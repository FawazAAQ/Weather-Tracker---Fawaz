# Weather Tracker - Fawaz

A Streamlit app for logging temperature, weather conditions, humidity and wind speed made following the GA Data Science deliverables. 
Use the dashboard to see temperature trends, search observations by date or condition and upload or download your data as a CSV.

app.py runs the interface, and myutils.py handles CSV loading, logging, filtering and statistics.

The app has a 
- Home page with an introduction 
- Log Observation page where the user can input the weather with the date
- Dashboard page where you can see the trend of the weather through every observation
- Search page where user can search for a specific date to view or specific condition or both
- View All Data page where all observations are present and can be downloaded

User can also upload their own data to view from
